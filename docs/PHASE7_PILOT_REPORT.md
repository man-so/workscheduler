## 1. 검증 범위

Phase 7에서는 새 기능 추가보다 실제 업무 파일럿 흐름 검증에 집중했다. 테스트 데이터는 모두 개인정보가 없는 가상 직원명(`Pilot-01` ~ `Pilot-16`)을 사용했다.

검증한 조건:

- 주간근무, 야간근무, 주간 조기출근, 야간 조기출근
- 주 4일제 및 주 5일제 혼합
- 연차 및 휴무 신청
- 야간근무 후 휴식 및 다음날 휴무
- 연속근무 제한
- 요일별 필요 인원
- 직원별 근무 가능 유형
- 야간근무 공정성

외부 AI 에이전트에는 실제 직원명이나 민감한 휴무 사유를 전송하지 않았다.

## 13. 결론

Phase 7 실제 업무 파일럿은 핵심 흐름 기준 **PASS**다.

설치형 Electron 앱에서 가상 팀을 생성하고, 승인된 설정을 Codex CLI에 전달해 Constraint JSON을 생성한 뒤, OR-Tools로 월간 근무표를 만들고, 검증/확정/Excel 내보내기/재조회까지 완료했다. Hard Constraint 위반, 직원 누락, 중복 배정, 휴무 위반은 모두 0건이었다.

다만 실제 현장 파일럿 전에 생성 시간과 자연어 공정성 기준 해석은 개선하는 것이 좋다. 따라서 현재 상태는 **제한적 파일럿 가능**, 대규모 팀이나 반복 생성 업무에는 성능 개선 후 확대 권장으로 판단한다.
